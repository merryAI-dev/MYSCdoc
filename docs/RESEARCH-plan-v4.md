> 작성: 2026-07-28
> 상태: **seed42 smoke 실행 완료, H1 미지지, 봉인셋 미개봉**
> 2026-07-28 개정: 학습 코드·문헌 감사 결과를 반영해 동시 대조군을 추가했다.
> 사람 대조는 시간 제약상 생략했다. 32B 수치는 구조적 골드와 육안 민감도 분석을 함께 보며 잠정치로 유지한다.

## 0. 새 골드로 무엇이 바뀌었나

공통 281건을 질문에 실제로 제공된 사실만 보고 다시 판정했다.

- 답변 가능 127 / 부분 답변 32 / 답변 불가 92 / 모호 30
- 기존 자동 라벨과 새 판정이 답변 가능↔불가로 뒤집힌 항목이 91건이다.
  - 기존 답변 가능 → 새 답변 불가: 45
  - 기존 답변 불가 → 새 답변 가능·부분 답변: 46
- 모호 30건은 주 지표에서 제외했다. 부분 답변 32건은 답변 대상으로 계산했다.

사전에 선택됐던 체크포인트와 사후 제품 후보를 같은 281개 사례(232개 고유 질문, 양·음 쌍 49개)에서 다시 계산한 결과다.

Honesty의 페어드 부트스트랩 95% 구간은 모든 모델 쌍에서 0을 포함했다. 현재 표본으로
“v3가 종합적으로 최고”라고 결론 내릴 수 없다. 대신 오류 방향은 분명하다.

- v2 step342가 답해버린 답변 불가 25건 중 v3는 19건에서 멈췄다.
- v2 step342가 답한 답변 대상 중 v3는 17건을 새로 완전 거절했다.
- v3는 Prudence를 얻는 대신 과잉거절을 사는 방향으로 이동했다.

## 1. v4 가설

**H-v4.** 같은 질문에서 결정적 근거 노드의 유무만 달라지는 경계쌍을 학습하면,
v3의 Prudence 이득을 가져오면서 v2의 낮은 과잉거절과 확정도 표현을 유지할 수 있다.

핵심은 “애매하면 더 거절하라”를 추가하는 것이 아니다. 모델이 실제 근거의 존재 여부를
구분하도록 같은 질문의 양성·음성 쌍을 보여준다.

이 가설은 세 결과를 함께 따른다.

- Hallucination Tax of RFT는 불능 문항 혼합이 거절을 회복시키지만 혼합 비율이 높아지면
  답변 정확도와 trade-off가 생김을 보였다. 따라서 v4에서는 비율을 바꾸지 않는다.
- OCC-RAG는 gold context를 줄여 hard refusal을 만들고, answerability 경계를 명시적으로
  학습했다. 다만 300만 건·약 90억 토큰 mid-training 결과이므로 우리 소규모 SFT의 효과량
  근거로 직접 쓰지 않는다.
- Wen et al. (EMNLP 2024)은 같은 질문도 context 제거·치환 방식에 따라 abstention이 크게
  달라짐을 보였다. 따라서 질문만 맞춘 음성 예가 아니라 나머지 context까지 고정한 쌍을 쓴다.

## 2. 단 하나만 바꾼다

기준은 v2 학습 레시피다. 역사적 v2 checkpoint는 외부 비교 대상으로만 남긴다. 학습 코드의
암묵적 기본값과 데이터 중복을 사후에 발견했으므로, 인과 비교는 같은 코드·환경에서 새로 돌린
`v4-control`과 `v4-treatment` 사이에서 한다.

고정하는 것:

- 기반 모델, LoRA 설정, optimizer, learning rate, matched seed, epoch/save 간격
- v2 시스템 프롬프트와 해요체 문체
- 전체 train 449건 / dev 79건과 답변·거절 클래스 수
- 교사 모델, 디코딩, 최대 토큰

바꾸는 것:

- train의 기존 답변 32건과 거절 32건을 **32개 근거 경계쌍**으로 일대일 교체한다.
- 각 쌍은 질문이 같고 사실 목록만 다르다.
  - 양성: 질문을 직접 뒷받침하는 결정적 사실을 포함
  - 음성: 그 사실만 제거하고 주제상 가까운 사실은 남김
- 총 행 수와 클래스 비율은 그대로 유지한다.

대조:

- `v4-control`: 감사된 v2 내용과 순서를 그대로 사용
- `v4-treatment`: control의 32개 답변 + 32개 거절만 32개 경계쌍으로 교체
- seed 42·43·44에서 control/treatment를 짝지어 총 6회 학습한다. deterministic algorithms를
  켜고 같은 seed끼리 비교한다.
- 두 run의 모델·코드·학습 recipe·SFT 설정·dependency·runtime fingerprint가 같아야 하며,
  dev 79건은 byte-equivalent여야 한다. 데이터 hash가 다르므로 전체 run signature 자체는 달라진다.
- 기존 v2 train에는 완전히 같은 거절 답변이 두 번 있으며 원 라벨은 각각 `answerable`,
  `unanswerable_hard`였다. content는 같으므로 두 군에 공통으로 남기되, 원 라벨을 클래스 근거로
  사용하지 않고 중복 사실을 보고한다. 교체 대상에는 포함하지 않는다.

테스트 281건의 문장이나 사실은 학습 재료로 쓰지 않는다. 오류 사례에서는 유형만 추출한다.

## 3. 데이터 격리

현재 281건은 이미 v4 가설 수립에 사용했으므로 앞으로 **audit/dev 세트**로 부른다.
v4의 최종 성능을 이 세트로 확증하지 않는다.

1. **선택셋:** 기존 199행(167개 질문: 단일 135 + 양·음 경계쌍 32)을 같은 기준으로 블라인드 재라벨링한다. 체크포인트 선택은 여기서만 한다.
2. **v4 학습 후보:** 학습·선택·281 audit과 겹치지 않는 미사용 질문에서 경계쌍 32개를 만든다.
3. **새 봉인 테스트:** 별도의 미사용 질문 150개로 양성/음성 경계쌍 300건을 만든다.
   쌍은 한 split에 같이 두고, v4 체크포인트가 고정될 때까지 모델 출력을 생성하지 않는다.
4. 질문 정규화 해시와 `(question, facts)` 해시로 네 집합 간 겹침 0을 확인한다.

봉인 테스트는 조건부 오류율을 재기 위한 균형 세트다. 실제 트래픽 유병률을 주장하는 용도가 아니다.

## 4. 선택과 성공 기준

### 체크포인트 선택 — 선택셋에서만

- treatment의 seed 3개를 합쳐 epoch별 지표를 내되, 같은 질문의 세 응답은 하나의 cluster로 다룬다.
- 제약: 과잉거절률(FRR) ≤ 10%의 question-clustered 단측 95% 상한.
- 6개 epoch에 Bonferroni 보정해 제약 만족 후보를 인증한다.
- 인증된 후보 중 failure-to-abstain rate가 가장 낮은 **공통 epoch**를 고르고, 같은 epoch를
  control과 treatment의 seed 3개에 모두 적용한다.
- 인증 후보가 없으면 v4는 실패로 판정하고 봉인 테스트를 열지 않는다.

### 봉인 테스트 — 선택한 공통 epoch의 6개 모델을 한 번만

모두 충족해야 성공이다.

- treatment의 과잉거절률 ≤ 10%를 question-clustered 95% 단측 구간으로 충족
- Prudence ≥ 80%
- 확정도 반영 ≥ 90%
- 답변 생성 실패 0건
- 합쇼체 혼용 ≤ 30% (v3의 53% 회귀 방지)
- 경계쌍 정확도(한 쌍의 양성은 답하고 음성은 거절)와 그 pair-clustered 95% 구간을 함께 보고
- seed별 원자료와 matched control→treatment 차이를 함께 보고한다. seed 평균만 단독으로 내지 않는다.

v1 step175, v2 step342, v3 step148도 같은 봉인 테스트에서 한 번에 생성해 비교하되,
v4 결과를 본 뒤 모델·체크포인트·기준을 바꾸지 않는다.

여기서 쓰는 Honesty는 Alignment for Honesty의 수식을 context answerability에 적용한
`Grounded Honesty`다. 원 논문의 Prudence는 정렬 전 모델이 틀리거나 모르는 문항에 대한
변화량이므로, 동일한 지표라고 주장하지 않는다.

## 5. 먼저 막아야 할 평가 위험

현재 32B 채점기는 모든 모델의 지어냄을 0%로 냈다. 사람이 아직 이 판정을 검증하지 않았으므로
“지어냄 0”은 결론이 아니라 경고 신호다.

학습 전 다음을 먼저 한다.

1. 모델·골드 범주·32B response 판정을 층화한 100건을 블라인드 육안 판정한다.
2. response 3분류 정확도와 Cohen's κ를 계산한다.
3. `fabricated`는 별도로 정밀도·재현율을 계산한다.
4. κ < 0.70 또는 주요 오류율 절대오차 > 3%p면 채점 프롬프트를 고치고 기존 전 모델을 재채점한다.

학습 코퍼스도 기존 job label을 그대로 믿지 않는다. 위 중복 사례처럼 `answerable` 라벨인데
교사 답변은 완전 거절인 행이 존재한다. 사람 대조를 통과한 판정기로 v2의 528개 completion을
다시 분류하고, 교체 64건의 실제 answer/refusal 구성이 32/32인지 확인한다.

## 6. 실행 순서와 중단 규칙

1. 선택셋 199건 골드 확정
2. 32B 채점기 100건 사람 대조
3. v2 학습 completion 재판정 및 상충 라벨·중복 보고
4. 경계쌍 32개 생성 및 네 집합 겹침 0 검증
5. 같은 코드로 v4-control과 v4-treatment 학습
6. 선택셋에서 각 checkpoint 인증·선택
7. 선택 모델 merge/export 후 실제 질문 20~30건 로컬 추론
8. 위 단계가 모두 통과할 때만 봉인 테스트 1회

봉인 테스트 실패 뒤 같은 테스트를 보며 v4b를 만들지 않는다. 다음 실험이 필요하면 새 봉인 세트를 만든다.
