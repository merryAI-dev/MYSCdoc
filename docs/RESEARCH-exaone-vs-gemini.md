# 연구 설계 — 한국어 회의록 → 지식그래프 추출에서 소버린 모델은 프론티어 API를 대체할 수 있는가

> 상태: 설계 초안 (2026-07-27). 실험 미실시.
> 대상: 사내 한국어 회의록·Slack → (주어,서술어,목적어) 지식그래프.

## 1. 문제와 가설

**선행 관측 (A2A, `judge_cases/EXAONE_이식성_검증.md`)**
같은 파이프라인에서 Gemini를 K-EXAONE으로 교체했을 때 —
- 공학적 이식은 성공: 스키마 6/6, 호출 실패 0, 20축 전부 채움
- **판단은 이식 실패**: 결정 라벨이 6건 중 5건 `conditional`로 쏠림 (Gemini 4종 → EXAONE 2종)
- 저자 권고: *"결정 라벨 판정을 프롬프트에서 결정론적 게이트로 이전"*

**우리 가설 (H1)**
> 판단(=이게 결정인가?)을 **한국어 어미 기반 결정론적 게이트**로 옮기고 모델에게는
> **구조화 추출만** 맡기면, 소버린 모델과 프론티어 API의 격차가 유의하게 줄어든다.

근거: A2A 실측상 "구조화 추출은 이식되고, 뉘앙스 판단은 이식되지 않는다". 그렇다면
판단을 모델 밖으로 빼는 것이 격차 해소의 지렛대다.

**부가 가설 (H2)**
> 한국어 결정 modality(`-기로 하다`, `-도록`, `-겠-`)는 어휘 매칭보다 **정밀도가 높고**,
> LLM 산출물이 아니라 **원문**에 적용해야 신호가 산다.

예비 실측(본 저장소, n=400/400 + 원문 4,587문장):

| 적용 대상 | 방식 | 재현율 | 정밀도 |
|---|---|---|---|
| LLM이 재작성한 statement | syntax(어미) | 20.3% | **92.0%** |
| LLM이 재작성한 statement | keyword(어휘) | 30.5% | 85.9% |
| 원문 문장 4,587개 | syntax | 218건 포착 (4.8%) | — |
| 원문 문장 4,587개 | keyword | 333건 포착 (7.3%) | — |

→ LLM 재작성문에서는 원문 어미가 소실되므로(해요체 평서문으로 평탄화) **게이트는
파이프라인 앞단(원문)에 놓아야 한다**. 이것 자체가 설계 시사점.

## 2. 기여 (주장하려는 것)

1. **결정의 사건 노드 분해(reification) 스키마** — 결정을 단일 엣지가 아니라
   `(결정:대상)-주체/값/근거/조건/기각대안->`로 분해. 정책이 질의 가능해진다.
   본 저장소 실측: 사건당 값 1.11·근거 0.61·기각대안 0.11 (분해 전에는 전부 0).
2. **어미 기반 결정론적 게이트 + 자동 충실성(faithfulness) 프록시** — 추출된 결정이
   원문의 결정 modality 문장으로 역추적되는지 자동 검사. 사람 라벨 없이 환각을 잡는다.
   (한국어 교착어 특성을 이용한 값싼 검증 — 영어 중심 파이프라인엔 없는 수단)
3. **소버린 모델 대조** — 위 두 장치 위에서 EXAONE과 Gemini Flash를 같은 문서로 비교.

## 3. 실험 설계

**데이터**: 사내 회의록 166문서 (2026-03~07, Drive+Tiro). 원문은 비공개, **집계 지표만 공개**.

**조건 (같은 문서·같은 스키마)**
| 조건 | 추출 모델 | 판단 게이트 |
|---|---|---|
| A (기준선) | Gemini 2.5 Flash | 없음 (모델이 판단) |
| B | EXAONE-3.5 | 없음 (모델이 판단) — A2A 재현 |
| C | EXAONE-3.5 | **어미 게이트** (H1 검증) |
| D (선택) | Gemini 2.5 Flash | 어미 게이트 (게이트 단독 효과 분리) |

**지표 (전부 자동 — 사람 라벨 불필요)**
1. `schema_valid`: JSON 파싱·필수 필드 충족률
2. `entity_nounphrase`: 개체가 명사구인 비율 (문장형 0 목표)
3. `decision_completeness`: 사건당 값·근거·조건·기각대안 커버리지
4. **`syntax_grounding`**: 추출된 결정이 원문의 modality 문장에 정렬되는 비율 ← 핵심 신규 지표
5. `predicate_entropy`: 서술어 분포 집중도 (파편화 척도)
6. `graph_connectivity`: 허브 개체 수·고립률
7. `cost_latency`: 문서당 초·원

**보조**: LLM-as-judge 교차 채점(양방향, 위치 편향 통제)은 자동 지표를 보완하는
용도로만. A2A가 지적했듯 **Gemini 출력은 정답이 아니라 기준선**이다.

**반복**: 조건당 3회 (A2A 한계 §4.1 — n=6·1회 반복 미측정 문제를 피함).

## 4. 정직한 한계 (미리 명시)

1. **정답 앵커 부재.** 회의록 추출의 golden triple이 없다. 자동 지표는 *구조 품질*을
   재는 것이지 *사실 정확성*이 아니다. 사실성은 표본 인간 검수로만 보완 가능.
2. **단일 조직·단일 도메인** 데이터라 일반화 주장 불가.
3. 원문 비공개라 재현 불가 — **코드·프롬프트·지표 스크립트는 공개**, 데이터는 집계만.
4. 형태소 분석기(Nori/mecab-ko-dic)의 외래어 오분석 존재 (예: `온보딩` → `오/VV + 보딩`).
   사용자 사전으로 보정하되, 보정 전후를 함께 보고한다.
5. EXAONE 접근 경로(로컬 MLX vs 외부 엔드포인트)에 따라 지연·비용이 달라짐 — 분리 보고.

## 5. 열린 결정 사항

- **EXAONE 구동**: 로컬 MLX(소버린·무료·느림) vs 외부 추론 엔드포인트(빠름·API 의존).
  후자는 사내 API 정책 검토 대상.
- **투고처**: 한국어 NLP 학회(한글및한국어정보처리 등) vs 응용 시스템 트랙.
- **사용자 사전** 구축 범위 (사내 고유명사·외래어).
